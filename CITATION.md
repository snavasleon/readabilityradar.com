# Citation

Use the repository URL, a tagged release, and the access date when citing this
software. Before submitting an article, replace the contributor placeholder
with the project authors and add the final release version.

Suggested format:

> Web Readability Radar contributors. (2026). *Web Readability Radar*
> (Version X.Y.Z) [Computer software]. GitHub. https://github.com/OWNER/web-readability-radar
