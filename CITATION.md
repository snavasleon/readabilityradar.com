# Citation

Use a tagged release and the access date when citing this software. The
archived DOI, when created through Zenodo, should be used in preference to the
repository URL for a formal publication.

Suggested format:

> Navas León, S., & Duñabeitia, J. A. (2026). *Web Readability Radar*
> (Version 1.1.1) [Computer software]. GitHub.
> https://github.com/snavasleon/readabilityradar.com
